HOME PAGE BANNER
================
Put the product video or advertisement image for the top of the home page in this folder.

- Videos: .mp4 (best, plays on every phone and browser), .webm or .mov. Up to 100 MB.
- Images: .jpg, .png, .webp or .gif. Wide pictures (16:9) look best.
- If there is more than one file here, the NEWEST one is shown.
- Delete all files here to go back to the standard welcome section.

You can also upload/replace/remove it from the admin panel: /admin -> Home banner.
